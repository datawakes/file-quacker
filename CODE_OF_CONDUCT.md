# Code of Conduct

This project uses the Contributor Covenant, version 2.1, as its code of conduct:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Please be respectful, constructive, and considerate when opening issues, submitting pull requests, or participating in discussions.

## Reporting

If you experience or witness behavior that violates the Code of Conduct, please report it privately to the project maintainer.

If the project does not list a separate contact method, you may use GitHub's private reporting channel under **Security → Advisories → Report a vulnerability**. Include "Code of Conduct report" in the title so it can be handled appropriately.

Reports will be reviewed as promptly as possible and kept confidential.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants when needed to keep the project respectful and productive.
